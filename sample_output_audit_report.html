Images must have alternate text ● NEW
Rule: image-alt · WCAG 1.1.1 · 3 elements affected · Page: /pricing
What's wrong

Three <img> elements inside the new <PricingCard> component have no alt attribute. Screen reader users hear "image" three times with no context about what the images depict (plan icons for Starter, Pro, and Enterprise tiers).

Affected selectors

.pricing-card:nth-child(1) img
.pricing-card:nth-child(2) img
.pricing-card:nth-child(3) img

✦ Claude Fix Suggestion

Add descriptive alt text to each pricing tier image. Use the tier name as the alt value — these are informational images, not decorative.

<!-- In PricingCard.jsx --> <img src={plan.icon} /> <img src={plan.icon} alt={`${plan.name} plan icon`} />

Form elements must have labels ● NEW
Rule: label · WCAG 1.3.1 · 1 element affected · Page: /contact
What's wrong

The new newsletter signup input field on the /contact page has no associated <label> element and no aria-label attribute. Screen reader users cannot determine what information the field expects.

Affected selector

#newsletter-email-input

✦ Claude Fix Suggestion

Add a visible label or an aria-label attribute. Using a visible label is preferred — it helps all users, not just screen reader users.

3
The intelligence: diff → smart filter → Claude
1:15–2:30
Say"This is the part that makes it smart, not just an axe-core wrapper. The Diff Engine compares this scan to last week using a stable key — so it knows 7 are new, 1 is persisting, and 2 were resolved. Only the NEW critical and serious ones go to Claude — that's 5 calls, not 8 — which is the cost-control routing. Claude returns a structured fix for each: plain-English explanation, who's affected, the exact code change, and an effort estimate."
Show Click the Diff Engine node output (7 new / 1 persisting / 2 resolved, score 62/100 vs 70). Then the Claude AI node — open one output item and read the JSON: the color-contrast fix returns the exact replacement color #B5720A and new ratio 5.2:1.
  • Emphasize: "It computes the replacement color and verifies the ratio — that's reasoning, not reformatting."
  • Point at the Parse + Merge node's try/catch — malformed JSON falls back to a rule-based suggestion instead of crashing.

Scale + honest limits
3:30–4:00
Say"I stress-tested it across 50 domains in one reproducible run — 232 violations, 130 Claude calls after the smart filter, 50 reports rendered, zero fatal errors. The whole path to 1,000 domains/day runs about $13.50/day. Anyone can rerun it with one command: node scale_test_50.js."
Show The 50-domain dashboard (outputs/screenshots/scale_test_50_dashboard.png), the Scale Testing table (Part 3), and outputs/pipeline_error_log.txt showing the recovered timeouts.
Key points to land

The three things to make sure they hear

  • Real intelligence, not an API call: Claude computes specific replacement colors + contrast ratios and traces multiple violations to one root-cause component.
  • Cost-control by design: the diff engine + smart filter mean we only pay for NEW critical/serious issues — 5 calls for 8 violations, and persisting issues are never re-billed.
  • Honest engineering: I know exactly where it breaks (heap at ~380 items) and exactly how to fix it. That's a production mindset, not a demo.

Backup plan if the live demo fails

If n8n won't run or the API is down

  • Pre-generated outputs: the entire outputs/ folder is committed — walk through those files directly instead of a live run.
  • Reproduce offline: run node generate_outputs.js — it replays captured Claude responses and regenerates every report with no API key needed.
  • Screenshots: the Output Gallery (Part 2) and architecture diagram (Part 4) on the Figma board cover every step visually.
  • Flagship artifact: open sample_output_audit_report.html — the full hand-reviewed report — as the fallback "hero" output.
